# Changelog

## v0.1.0-prototype (2026-10-13)

- Evidence-based surface audit and six-ecosystem tooling benchmark.
- Typed proposed market/account services with explicit synthetic adapter.
- Exact finite decimals and generic bounded HTTP transport, errors, retries,
  Retry-After, optional interval limiting and sanitized request hooks.
- Bounded local stream replay and gap-aware synthetic order-book recovery.
- Read-only CLI, five short examples, signing/trading/agent design and grant package.
- Offline validation and CI configuration; no official TxFlow compatibility claim.

Live read endpoints, WebSocket/reconnect, signing, trading and agent authorization
are pending permission and canonical specification. This prerelease is an offline foundation, not a production SDK release.
